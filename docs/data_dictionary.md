# Data Dictionary

## Overview

This document describes every column used in the CareerLens-AI dataset.

| Column | Description | Data Type |
|----------|------------|-----------|
| Job Title | Title of the job | String |
| Company | Company offering the job | String |
| Location | Job location | String |
| Salary | Salary offered | Numeric |
| Skills | Required technical skills | String |
| Experience | Years of experience required | Integer |
| Industry | Industry category | String |
| Job Type | Full-time / Part-time / Contract | String |
| Work Mode | Remote / Hybrid / Onsite | String |
| Posted Date | Date the job was posted | Date |

> **Note:** This document will be updated after the dataset is finalized.
